# 📚 Python Library Management System

A simple **menu-driven Library Management System built with Python** using **Object-Oriented Programming (OOP)** concepts.

The program allows users to view available books, borrow books, return books, and exit the library system.

## ✨ Features

* 📖 View available books
* 📥 Borrow a book
* 📤 Return a book
* ⚠️ Checks whether a book is available before borrowing
* 🔄 Prevents adding a book that is already in the library
* 📋 Simple menu-driven interface
* 🏗️ Uses classes and methods to manage library operations

## 🛠️ Technologies Used

* **Python**
* **Object-Oriented Programming (OOP)**
* Lists
* Loops
* Conditional statements
* User input

## ⚙️ How It Works

The project uses a `Library` class that stores a list of books.

The class contains three main methods:

* `available_books()` — displays all books currently available.
* `borrow_book()` — checks whether the requested book is available and removes it from the library if found.
* `return_book()` — adds a returned book back to the library if it isn't already available.

The user interacts with the system through a menu with four options:

```text
==========Library menu==========
1. Available books
2. Borrow a books
3. Return a books
4. Exit
```

The program continues running until the user chooses the **Exit** option.
