# 🧮 Python Calculator

A simple **menu-driven calculator built with Python** using **Object-Oriented Programming (OOP)** concepts.

The calculator allows the user to perform basic mathematical operations such as **addition, subtraction, multiplication, and division**.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🛡️ Handles division by zero
* 📋 Simple menu-driven interface
* 🏗️ Uses a Python class and methods for calculations

## 🛠️ Technologies Used

* **Python**
* **Object-Oriented Programming (OOP)**
* `match-case`
* Exception handling with `try-except`

## ⚙️ How It Works

The project uses a `Calculator` class containing separate methods for each mathematical operation:

* `add()` — performs addition
* `subtract()` — performs subtraction
* `multipliction()` — performs multiplication
* `division()` — performs division and handles `ZeroDivisionError`

The user selects an operation from the menu and then enters two numbers. The selected method performs the calculation and displays the result.

### Example

```text
---------Welcome to the calculator---------
1. Additon
2. subtraction
3. multipliction
4. division

Please select any option between 1-4: 1
Enter first number: 10
Enter second number: 5

The sum of 10 and 5 is 15
```
