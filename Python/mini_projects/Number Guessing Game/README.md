# 🎯 Python Number Guessing Game

A simple **Number Guessing Game built with Python** where the player tries to guess a randomly generated number between **1 and 50**.

The program provides hints after each guess and keeps track of the number of attempts taken to find the correct number.

## ✨ Features

* 🎲 Generates a random number between 1 and 50
* 🎯 Allows the player to repeatedly guess the number
* ⬆️ Tells the player when their guess is smaller than the target
* ⬇️ Tells the player when their guess is greater than the target
* 🏆 Displays a congratulatory message when the number is guessed
* 🔢 Counts the number of attempts taken

## 🛠️ Technologies Used

* **Python**
* Random number generation
* `while` loop
* `if-elif-else`
* User input
* Variables and counters

## ⚙️ How It Works

At the beginning of the game, a random number between **1 and 50** is generated.

The player is then repeatedly asked to enter a guess.

The program compares the player's guess with the randomly generated number:

* If the guess is **correct**, the player wins.
* If the guess is **smaller**, the program displays `"Your number is smaller"`.
* If the guess is **greater**, the program displays `"Your number is greater"`.

The game also counts every attempt and displays the total number of attempts after the correct number is guessed.

## 🎮 Example

```text
Guess the number between 1-50: 25
Your number is smaller

Guess the number between 1-50: 40
Your number is greater

Guess the number between 1-50: 32
Congrats, you guessed the number

You guessed the number 32 in 3 attempts
```
