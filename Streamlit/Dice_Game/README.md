# ⚔️ Dice Battle 🎲

A simple **two-player dice battle game** built using **Python and Streamlit**.

In this game, two players roll a dice. The player with the higher number wins the round and deals damage to the opponent. Each player starts with **120 health points**, and the battle continues until one player's health reaches zero.

## 🎮 How the Game Works

1. Enter the names of the two players.
2. Click **Start Game**.
3. Both players roll their dice.
4. The player with the higher dice number wins the round.
5. The difference between the dice values determines the damage.
6. The losing player's health decreases.
7. If both players roll the same number, the round is a draw.
8. The battle continues until one player's health reaches **0**.
9. The remaining player wins the battle. 🏆
